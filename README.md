# Unique Gym - Proyecto Integrador Oficial

Repositorio oficial para el cliente **Unique Gym**, desarrollado en el programa Técnico en Programación de Páginas Web (INFOTEP)[cite: 22].

## Cliente y Alcance del Sitio
- **Cliente:** Unique Gym (Centro Fitness & Entrenamiento Personalizado)[cite: 22].
- **Alcance:** Página web corporativa responsive con catálogo de servicios, horarios de clases, planes de membresía y formulario de registro/contacto[cite: 22].

## Sistema de Diseño (Módulo 3)
El sistema de diseño se encuentra versionado internamente en la ruta `/css/design-system/` e incluye[cite: 22]:
- Paleta cromática de alto contraste (*Studio Fitness & High-Contrast Neons*)[cite: 22].
- Tipografía *Montserrat* e *Inter* con escala cerrada de 8px[cite: 22].
- Componentes reutilizables (Botones, Tarjetas, Campos de Entrada)[cite: 22].

## Estructura de Directorios (Módulo 2)
- `/css`: Hojas de estilo generales y sistema de diseño versionado[cite: 22].
- `/js`: Scripts de interacción y lógica de navegación[cite: 22].
- `/img`: Recursos gráficos corporativos y logotipos[cite: 22].
- `/docs`: Documentación técnica y vistas secundarias[cite: 22].
- `index.html`: Página principal de presentación[cite: 22].
