# Unique Gym - Proyecto Integrador Oficial

Repositorio oficial para el cliente **Unique Gym**, desarrollado en el programa Técnico en Programación de Páginas Web (INFOTEP).

## Cliente y Alcance del Sitio
- **Cliente:** Unique Gym (Centro Fitness & Entrenamiento Personalizado).
- **Alcance:** Página web corporativa responsive con catálogo de servicios, horarios de clases, planes de membresía y formulario de registro/contacto.

## Sistema de Diseño (Módulo 3)
El sistema de diseño se encuentra versionado internamente en la ruta `/assets/css/design-system/` e incluye:
- Paleta cromática de alto contraste (*Studio Fitness & High-Contrast Neons*).
- Tipografía *Montserrat* e *Inter* con escala cerrada de 8px.
- Componentes reutilizables (Botones, Tarjetas, Campos de Entrada).

## Estructura de Directorios (Módulo 2)
- `/assets`: Recursos globales del sitio.
  - `/assets/css`: Hojas de estilo generales y sistema de diseño versionado.
  - `/assets/js`: Scripts de interacción y lógica de navegación.
  - `/assets/img`: Recursos gráficos corporativos y logotipos del gimnasio.
- `/pages`: Páginas y secciones internas del sitio web (`nosotros.html`, `clases-horarios.html`, etc.).
- `/docs`: Documentación técnica y vistas secundarias.
- `index.html`: Página principal de presentación.
